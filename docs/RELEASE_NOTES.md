# v1.0.0 — First public release

- Transparent two-row icon toolbar for Windows window ordering.
- Always-on-top, normal and always-on-bottom groups with drag ordering.
- Toolbar self-management, tray actions and recovery shortcut.
- Per-pixel alpha rendering, outlined white text and a rounded frame.
- Small draggable grip with a contiguous hit area between the dots.
- Local named profiles and a rebuildable .NET Framework source tree.

Exclusive fullscreen and secure desktop are not guaranteed. The executable is unsigned. GUI integration checks require an interactive Windows desktop.
