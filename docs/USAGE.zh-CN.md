# 使用说明

上排参与管理，下排自由切换；左侧图标排在右侧图标前面。首次拖入空的上排默认置顶。右键选择置顶、普通或置底，跨组拖动时继承落点分组。

左上角点阵围成的整块小区域都能拖动，包括点之间的空隙。点阵外围保持可点击穿透。拖动图标时临时显示接收区域，结束后恢复透明。

右上角可切换锁定、刷新列表或打开菜单。菜单包含保存和加载方案、隐藏到托盘、退出。隐藏不会自动解除锁定。

要让工具栏自身更容易访问，把它自己的图标放在上排第一位并设为置顶。Ctrl + Alt + F11 可以唤回工具栏；独占全屏不保证支持。

方案保存于程序旁的 profiles.xml。名称和模式保存在本机，加载后需确认再开始锁定。窗口标题发生变化可能导致匹配失败。

## 桌面快捷方式和登录自启动

本项目不自动修改启动配置。需要时，可对 WindowLayers.exe 创建快捷方式，并放到桌面或当前用户的 Windows“启动”文件夹。请把程序保存在固定位置，否则快捷方式会失效。

## 故障排查

- 没有效果：确认窗口在上排、已开始锁定，并检查该图标的模式。普通模式不等于置顶。
- 目标窗口是管理员运行：本工具可能需要相同权限。
- 被全屏挡住：使用 Ctrl + Alt + F11；独占全屏时先退出全屏。
- 快捷键无效：可能与其他软件冲突，可使用托盘菜单。
- 强制退出后仍置顶：重启目标应用，或重新设为普通并解除锁定。
